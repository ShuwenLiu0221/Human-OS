# Human OS

给自己的身体和生活写一份"操作手册"。

网上的健康建议太多，真假混在一起。这里每一条建议都写清楚五件事：要付出什么、用大白话讲是什么意思、能得到什么、证据有多硬、出处在哪。拿不出来源的，不收录。

## 每一条的格式

```
1. 一句话说清楚要做什么

成本：花多少钱、多少时间，难在哪里
说人话：不用术语，讲清楚这件事是什么、为什么
收益：研究或法律原文到底说了什么，尽量给出具体数字
证据等级：A / B / C
来源：作者 (年份). 标题. 链接
备注：适用人群、注意事项、容易误解的地方
```

投入产出比低的条目，标题前会标【投入产出低】，标题下方用提示框写明低在哪里：效果太小、证据太弱、花钱多但收益不确定，或者有风险。

## 证据等级

| 等级 | 含义 |
| --- | --- |
| **A** | 法律条文；权威指南的强推荐；或多项随机对照试验的荟萃分析，结论一致 |
| **B** | 指南的弱推荐或有条件推荐；随机对照试验数量少、样本小；大型观察性研究（只能说明相关、不能证明因果）；或者机制清楚但缺少直接试验 |
| **C** | 证据很少、质量很低，或者各项研究结论互相矛盾 |

证据等级说的是"这条结论有多可靠"，不是"这件事有多值得做"。比如 [睡眠第 18 条](./sleep.md#18-投入产出低褪黑素别当安眠药只对生物钟推迟的人有明显作用) 的结论是"褪黑素对普通失眠效果很小"，这个结论本身是比较可靠的。值不值得做，看每个模块开头的投入产出分档。
